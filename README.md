# Launch

Лаунчер домашнего экрана для Android TV. Текущая версия **1.34.0** (versionCode 36). Пакет `com.launch.tv`.

Установка этого лаунчера с телефона — **отдельное приложение**, не часть лаунчера. Оно называется «Установка Launch», пакет `com.launch.installer`, версия **1.0.3** (versionCode 4). Метка в Git: `installer-1.0.3`. На телевизор его не ставят.

Автор программы — **Mr.Box-600**. Launch не является продуктом Google, Xiaomi или Apple.

Главный экран устроен как рабочий стол: часы и погода в центре, избранные приложения внизу. Отдельные разделы есть для всех программ, входов телевизора, поиска и настроек.

## Возможности

- Домашний экран с часами, датой, погодой и доком избранного.
- Заставка при запуске: знак Launch, плавное появление и короткий звук.
- Щелчок и лёгкое увеличение иконки при переходе фокуса. Анимацию можно выключить в пункте «Анимации».
- Разделы «Все», «Входы», «Поиск» и «Настройки».
- Темы с фотографиями и отдельный градиентный фон. Можно поставить своё изображение.
- Размер иконок задаётся числом, от 24 до 180 dp.
- Входы HDMI и AV. Порт без сигнала подписан «Нет сигнала», отключённый — «Не подключён». На пустой порт переключиться нельзя.
- Погода по названию города или автоматически по сети. На телевизоре используются службы, которые он реально открывает: wttr.in, MET Norway и Open-Meteo.
- Отключение приложений с пометкой важных и критичных. Критичные системные пакеты не отключаются.
- Кнопка PatchWall на пульте Xiaomi открывает Launch.

## Требования

- Android TV или Google TV, Android 6.0 и новее (minSdk 23). Проверено на Xiaomi Mi TV, Android 11, экран 1920×1080.
- Для сборки: JDK 17, Android SDK с платформой 35, Gradle 8.11.1.
- Kotlin 2.1.20, Android Gradle Plugin 8.7.3, Jetpack Compose 1.10.3, AndroidX TV Material 1.1.0.

## Сборка

В корне проекта есть обёртка Gradle 8.11.1:

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\path\to\android-sdk"
.\gradlew.bat assembleRelease
```

Готовый файл:

`app/build/outputs/apk/release/app-release.apk`

Release-сборка подписывается отладочным ключом и не сжимается ProGuard. Это сделано, чтобы обновление поверх уже установленной версии проходило тем же ключом. Для публикации в магазин нужен свой ключ подписи.

Файл `local.properties` с путём к SDK в репозиторий не входит. Его создаёт Android Studio или его можно положить вручную:

```properties
sdk.dir=C:\\path\\to\\android-sdk
```

## Отдельное приложение: установка с телефона

Это не лаунчер. Модуль `:installer`, пакет `com.launch.installer`, имя на телефоне «Установка Launch». Телефон ищет Android TV в той же сети Wi‑Fi, один раз просит на экране телевизора «Разрешить» и ставит текущую сборку Launch. На телефоне остаётся только установщик. Сам Launch открывается на телевизоре.

Сборка установщика подхватывает release-файл лаунчера и кладёт его внутрь:

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\path\to\android-sdk"
.\gradlew.bat :installer:assembleRelease
```

Готовый файл: `installer\build\outputs\apk\release\installer-release.apk`. Его ставят на телефон, не на телевизор.

На телевизоре нужна обычная отладка по сети, обычно порт 5555. Пункт только с кодом сопряжения установщик не использует. Samsung на Tizen и LG на webOS приложение не меняет.

## Установка на любой телевизор

Launch ставится на Android TV и Google TV с Android 6.0 и новее. Отдельной привязки к Xiaomi нет. Нужны пульт, файл `app-release.apk` и один из двух способов ниже.

Соберите APK на компьютере, если готового файла ещё нет:

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\path\to\android-sdk"
.\gradlew.bat assembleRelease
```

Файл появится здесь: `app\build\outputs\apk\release\app-release.apk`.

### С флешки

1. Скопируйте `app-release.apk` в корень флешки.
2. На телевизоре откройте настройки и разрешите установку из неизвестных источников. Пункт обычно называется «Безопасность», «Приложения», «Специальный доступ» или «Неизвестные источники». На части телевизоров разрешение спрашивают уже в момент установки.
3. Вставьте флешку. Откройте её встроенным файловым менеджером или приложением «Файлы» и запустите APK.
4. Подтвердите установку пультом.

### С компьютера по сети

1. Телевизор и компьютер должны быть в одной сети.
2. На телевизоре включите «Для разработчиков» (часто семь нажатий на номер сборки) и «Отладка по сети» или «ADB по сети». Запомните IP-адрес. Порт обычно `5555`.
3. На компьютере нужен `adb` из Android SDK, папка `platform-tools`.

```powershell
adb connect 192.168.1.50:5555
adb -s 192.168.1.50:5555 install -r app\build\outputs\apk\release\app-release.apk
adb -s 192.168.1.50:5555 shell am start -n com.launch.tv/.MainActivity
```

Подставьте адрес своего телевизора вместо `192.168.1.50`. Если `adb devices` показывает `unauthorized`, подтвердите отладку на экране телевизора. Если устройство `offline`, выключите и снова включите отладку по сети и повторите `adb connect`.

Повторная установка той же версии может быть отклонена. Тогда поднимите `versionCode` в `app/build.gradle.kts` и соберите APK заново.

### После установки

Нажмите «Домой» на пульте. Если система спросит домашний экран, выберите Launch и подтвердите «Всегда». Тот же выбор есть в настройках телевизора в разделе приложений по умолчанию: «Главный экран» или «Домашний экран».

Постеры фильмов появляются только если приложения сами их публикуют. Чтобы лаунчер видел такие уведомления, в системных настройках откройте «Доступ к уведомлениям» и включите Launch. На многих телевизорах этот доступ закрыт подписью системы, и тогда остаются только те рекомендации, которые приложения отдают открыто.

Кнопка PatchWall есть только на телевизорах Xiaomi. На остальных моделях Launch открывается кнопкой «Домой», когда выбран домашним экраном.

## Пульт

| Кнопка | Действие |
| --- | --- |
| Влево и вправо | Переход между иконками и пунктами |
| OK | Открыть приложение или подтвердить пункт |
| Долгое OK | Меню приложения: избранное, скрыть, категория, сведения |
| Назад | Закрыть меню, выйти из подраздела, вернуться на главный экран |
| Кнопка телевизора / PatchWall | Открыть главный экран Launch |

На экране входов долгое OK добавляет порт в избранные. В углу главного экрана видны только входы, на которых есть сигнал.

## Настройки

Основные пункты: тема, обои, своё изображение, размер иконок, число карточек в ряду, анимации, часы, дата, погода и регион, избранное, скрытые, категории, роль домашнего экрана, PatchWall, отключение приложений, экран, сведения о приложении.

Страница «Экран» задаёт размер и формат часов, секунды, подложку, подписи дока, недавние, единицы погоды, затемнение фото, сортировку списка «Все», подтверждение отключения и звук фокуса.

Настройки хранятся на самом телевизоре. Их можно записать в локальный файл и прочитать обратно из настроек.

## Структура

```
app/src/main/java/com/launch/tv/   лаунчер для телевизора, пакет com.launch.tv
  MainActivity.kt          точка входа и кнопки пульта
  LaunchViewModel.kt       состояние экрана и команды
  model/Models.kt          разделы и настройки
  data/                    приложения, погода, входы, обои
  ui/                      главный экран, списки, настройки
  ui/theme/                палитры и темы
app/src/main/res/drawable-nodpi/   фотографии тем
installer/                       отдельное приложение для телефона, пакет com.launch.installer
```

Подробное описание экранов и условий использования: [docs/rukovodstvo.md](docs/rukovodstvo.md).
